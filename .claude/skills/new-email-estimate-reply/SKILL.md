# 新規メール → 基本情報依頼＋概算見積り＋アポ誘導の下書き

見込み客から新規メールが届いたら、次の3点を1通にまとめた返信を **Gmail の下書き** として作る。

1. **基本情報のお願い** — 個人なら個人情報フォーム、法人なら法人情報フォーム（どちらか一方だけ）
2. **概算見積り** — 用件に該当する業務の料金の目安（幅で、税込で、「目安」と明記）
3. **アポの誘導** — 初回相談（有料）の予約リンク

`inquiry-intake` スキル（初回返信の汎用版）と同じ方針に従い、こちらは **概算見積りを具体的に示す** ことに重点を置く。

## 既定の動作

- **下書きまで。自動送信しない。** 「送っていい」と明示されたときだけ送信する。
- 既に返信済み（こちらが最後に送っている）スレッドには作らない。
- 既存の顧問先・営業メール・求人・迷惑メールは対象外として一覧に挙げるだけにする。

## 参照するスキル（URL・金額は必ずここから取る。記憶で書かない）

| 用途 | スキル |
|---|---|
| 個人の基本情報フォーム URL | `personal-infomation` |
| 法人の基本情報フォーム URL | `corporate-info` |
| アポ予約リンク | `appointment` |
| 業務範囲・概算報酬・期間 | `tokyo-advisory-services`（返信の言語に合わせて `references/services-ja.md` / `services-en.md` を読む） |
| 国外財産調書の明細見積り（税抜） | `overseaassetreport`（資産内容が分かっているときのみ。税込/税抜を混ぜない） |
| 署名ブロック | `tokyo-advisory-profile` |

## 手順

### 1. 対象メールを拾う

- ユーザーがメールを指定したらそれを使う（差出人・件名・日付で Gmail `search_threads`）。
- 指定がなければ未返信の新規メールを探す。既定のクエリ:
  `to:contact@tokyoadvisory.com newer_than:14d -in:trash -in:sent`
  そのうえで **こちらが最後に返信していないスレッド** だけを対象にする。
- 対象スレッドは `get_thread` で全文を読む。

### 2. 個人か法人かを判定する

書いてある事実だけで判断する。推測で埋めない。

| 判定 | 手がかり |
|---|---|
| **法人** | 署名に会社名・役職、法人ドメイン、法人設立・KK/GK・法人税・記帳・決算・監査・給与・内部統制の話題、「弊社」「当社」 |
| **個人** | 個人の確定申告・米国申告・国外財産調書・相続/贈与・ビザ・納税管理人の話題、フリーメール、個人名のみの署名 |
| **判断不能** | 個人事業主で法人化を検討中、など両方に当てはまる場合 → 下書きを作る前にユーザーに確認する |

あわせて次も把握する:

- **言語**: 本文の言語で返信する（日本語 → 日本語、英語 → 英語）
- **業務領域**: `tokyo-advisory-services` §2 の A〜H のどれに当たるか
- **期限**: 申告期限・出国日・決算日・ビザ期限。1か月以内なら返信冒頭で触れ、報告でも印を付ける
- **見積りに効く情報**: 資産の数、取引量、売上規模、所得の種類、国数など、相手が既に書いていること

### 3. 概算見積りを組み立てる

1. `tokyo-advisory-services` の reference の §2 から、該当業務の行を読む。
2. 金額は **reference と一字一句同じ** にし、**幅で**（「120,000〜250,000円（税込・目安）」）書く。下限だけを書かない。
3. 相手の書いた内容から複雑な側（資産・取引が多い、複数国など）と分かる場合は、下限ではなくその旨を添える。
4. 業務が複数にまたがる場合は、業務ごとに1行ずつ並べる（合計額は作らない）。
5. 期間（§4）も分かれば「おおよそ◯週間」と添える。
6. 必ず「正式なお見積りは初回相談後、3営業日以内に書面でお送りします」と書く。
7. 次は守る:
   - **納税管理人は年110,000円（税込）。** 60,000円は誤りなので使わない。
   - `overseaassetreport` の明細（税抜）と `tokyo-advisory-services`（税込）を混ぜない。
     使う場合はどちらの基準かを明記し、迷ったらユーザーに確認する。
   - カタログ（§1・§2）にない業務・業務範囲外（ライフプランニング、住宅ローン、保険・投資商品）は
     見積りを出さず、範囲外である旨と提携先の紹介を申し出る。
   - 用件が曖昧で業務が特定できない場合は、無理に金額を出さず、該当しそうな業務の幅を最大2つまで示し、
     面談で確認する旨にする。

### 4. 返信を組み立てる

順序は **お礼 → 概算見積り → 初回相談（アポ誘導） → 基本情報フォーム → 署名** で固定。

- **初回相談は60分・33,000円（税込）、Zoom または六本木オフィス。無料ではない。**
  「初回無料」「無償で」とは絶対に書かない。
- 予約リンクは `appointment` の URL。
- 基本情報フォームは個人なら `personal-infomation`、法人なら `corporate-info` の URL を **1つだけ**。
  面談前に記入しておいてもらう位置づけで書く。相手がメールに既に書いている情報は重ねて訊かない旨を添えてよい。
- 署名は `tokyo-advisory-profile` の署名ブロック。

### 5. Gmail に下書きを保存する

- 元スレッドへの **返信の下書き** として `create_draft` で作る（`threadId` を指定、件名は元の件名に `Re:`、宛先は差出人）。
- 新規スレッドとして作らない。CC が元メールにあれば引き継ぐ。

### 6. ユーザーに一覧で報告する

チャットには表で示す。下書きの全文は貼らない。

| 差出人 | 用件 | 個人/法人 | 概算見積り | 期限 | 下書き |
|---|---|---|---|---|---|
| … | … | 個人 | 確定申告 ◯〜◯円 | 3/15 ⚠ | 作成済 |
| … | … | — | — | — | 対象外（営業メール） |

表の下に、判断に迷った点（個人/法人が不明、業務が特定できない、税込/税抜の扱い、範囲外の可能性など）を短く挙げる。

## 守ること

- **自動送信しない。** 下書きのまま置く。
- **金額・期間は必ず `tokyo-advisory-services` の reference を読んでから書く。** 幅で、税込で、「目安」と明記。
- **初回相談は有料（33,000円税込）。** 無料と書かない、匂わせない。
- **フォームは1つだけ。** 個人と法人の両方を貼らない。
- **URL はそれぞれのスキルから取る。** 推測した URL を書かない。
- **相手が書いていない事情を補わない。** 分からないことは面談で伺う旨にする。
